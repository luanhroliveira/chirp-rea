# Bancos

No UV-21 Pro (família UV-17ProGPS) os bancos são **fixos**: 10 bancos de 100 canais.

| Banco | Canais |
|---|---|
| 1 | 1–100 |
| 2 | 101–200 |
| … | … |
| 10 | 901–1000 |

Não é possível mover um canal de banco — para isso, mude o número do canal.
O que se edita é o **nome** de cada banco.

## Usar a aba

- A lista da esquerda mostra cada banco, sua faixa e quantos canais estão em uso.
- Clique num banco para ver os canais programados nele, à direita.
- Edite o nome e clique em **Salvar** (ou tecle Enter). Até 16 caracteres; use
  letras sem acento, números e símbolos.
- Envie para o rádio para gravar os nomes.

Nomes em chinês (GB2312) gravados por outros programas aparecem como `?`.
