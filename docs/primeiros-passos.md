# Primeiros passos

## A janela principal

| Área | O que é |
|---|---|
| **Menu Arquivo** | novo, abrir, configurações prontas, salvar, fechar aba |
| **Menu Rádio** | baixar do rádio, enviar para o rádio, alterar logo |
| **Abas de documento** | cada arquivo ou rádio aberto vira uma aba; `•` indica alterações não salvas |
| **Sub-abas** | Memórias, Configurações, Bancos, Informações, Navegador (as disponíveis dependem do rádio) |
| **Barra de status** | resultado da última ação ou mensagem de erro |

O tema claro/escuro acompanha o do Windows.

## Atalhos

| Atalho | Ação |
|---|---|
| `Ctrl+N` | novo documento (CSV) |
| `Ctrl+O` | abrir `.csv` ou `.img` |
| `Ctrl+S` | salvar |
| `Ctrl+W` | fechar a aba atual |
| `Alt+D` | baixar do rádio |
| `Alt+U` | enviar para o rádio |
| `Alt+L` | alterar a logo do rádio |

## Fluxo típico com um rádio

1. **Rádio › Baixar do rádio** ([detalhes](radio-baixar-enviar.md)).
2. **Arquivo › Salvar como…** e guarde um `.img` de backup antes de mudar qualquer coisa.
3. Edite [memórias](memorias.md), [configurações](configuracoes.md) e [bancos](bancos.md).
4. **Rádio › Enviar para o rádio**.

## Fluxo sem rádio

- **Arquivo › Novo** cria uma lista de canais em CSV.
- **Arquivo › Abrir configuração pronta** carrega listas como "US Calling Frequencies"
  ou "EU LPD and PMR Channels" (veja [Arquivos](arquivos.md)).
