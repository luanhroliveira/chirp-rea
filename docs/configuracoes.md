# Configurações do rádio

A sub-aba **Configurações** reúne as opções gerais do rádio, nos mesmos grupos do
CHIRP. As alterações ficam na imagem aberta; use **Rádio › Enviar** para gravá-las
no rádio. Só o que você muda é gravado: valores desconhecidos já presentes no
rádio são preservados.

## Básico

| Opção | O que faz |
|---|---|
| Squelch | sinal mínimo para abrir o alto-falante (Off = sempre aberto) |
| Timeout (tempo máx. de TX) | limita a duração de cada transmissão |
| Dual Watch | monitora as frequências A e B alternadamente |
| Tela ao ligar | logo ou tensão da bateria — com o botão **Alterar logo…** ([logo](logo.md)) |
| Idioma da voz / Voz ativada | idioma dos menus e anúncios por voz |
| Tempo da luz de fundo | quanto tempo o display fica aceso |
| Bloqueio automático do teclado | trava o teclado sozinho |
| Bipe / Roger beep | tom de tecla e tom de fim de transmissão |
| Display do canal A / B | mostrar nome, frequência ou número do canal |
| Economia de energia | desliga o receptor em ciclos para poupar bateria |
| Alarme do timeout | aviso antes do timeout cortar a transmissão |
| Tom piloto | 1000/1450/1750/2100 Hz para acesso a repetidoras |
| Side tone | quais tons DTMF também saem no alto-falante |
| Tail clear | reduz o ruído de fim de transmissão no outro rádio |
| Modo de varredura | Time, Carrier ou Search |
| Modo do alarme / Som do alarme | comportamento do alarme de emergência |
| Teclado travado | estado atual do bloqueio |
| Tempo de saída do menu | quando o menu fecha sozinho |
| Atraso do envio do ID | espera antes do ANI/PTT-ID |
| Gravar tom da varredura (QT) | onde salvar o CTCSS/DCS encontrado na varredura |
| Tecla lateral 2 | FM, Scan, Search ou Vox |
| Modo do canal A / B | VFO (frequência) ou memórias |
| Rpt tail clear / delay | eliminação do rabicho em repetidoras compatíveis |
| Menu de reset habilitado | libera o menu RESET no rádio |
| VOX / Nível / Atraso do VOX | transmissão por voz |
| GPS / Modo / Fuso | receptor GPS (modelos com GPS) |
| Desativar rádio FM | bloqueia o rádio FM comercial |

## Modo de trabalho › VFO A / VFO B

Frequência, shift (+/−/off), offset, potência, largura de banda (Wide/Narrow),
código PTT-ID e passo de sintonia de cada VFO. A frequência precisa estar dentro
das bandas do rádio.

## DTMF

- **Código 1–20** e **Nome do código**: códigos PTT-ID (`0-9 A-D * #`, até 5
  dígitos; nome até 10 caracteres).
- **Código ANI**: identificação automática do rádio.
- **Velocidade DTMF (tom/pausa)** e **Tempo de hang-up**.

## Nomes dos bancos

Os 10 nomes de banco (até 16 caracteres). É o mesmo valor editável na aba
[Bancos](bancos.md).
