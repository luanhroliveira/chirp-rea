# Galeria de imagens do desenvolvedor

Imagens usadas como "Minhas imagens" no diálogo de logo quando o app roda com
`./gradlew :app:run`. No app instalado, essa seção lê `%USERPROFILE%\.chirp-rea\logos`.

**Estas imagens são de terceiros** (ilustrações e estampas obtidas na internet,
incluindo personagens de *Os Simpsons*). Elas **não** são distribuídas sob a
GPL-3.0 do projeto e pertencem aos seus respectivos autores. Se você é autor de
alguma delas e quer que seja removida, abra uma issue.

As logos originais do projeto, livres para redistribuição, ficam em
`app/src/desktopMain/resources/logos/`.
